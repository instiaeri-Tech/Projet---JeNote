# Lancement commercial

## Proposition

« Votre vraie journée devient votre prochaine compétence. » JeNote part d’une situation réelle et la transforme en expression naturelle, explication, exercice, dialogue et révision.

## Capacités livrées dans le MVP enrichi

- compte JeNote indépendant, sans identification Manus.ai ;
- dictée vocale directement dans le compositeur ;
- mémo audio de session via le microphone ;
- import photo/document image avec OCR français + anglais ;
- répétition espacée, conversations guidées et export personnel ;
- PWA installable sur Android, iPhone/iPad, Windows, Linux et macOS.

## Installation utilisateur

1. Ouvrir l’URL de production dans Chrome, Edge ou Safari.
2. Choisir **Installer l’application** / **Ajouter à l’écran d’accueil**.
3. Créer un compte JeNote avec son adresse email et un mot de passe indépendant.
4. Autoriser le microphone ou l’appareil photo uniquement quand une capture est demandée.

## Offre à tester

- Gratuit : carnet limité et quota mensuel de transformations.
- Premium individuel : quota supérieur, audio et révisions avancées.
- Annuel : remise à tester après observation de la rétention.
- Entreprise/formation : seulement après validation de la valeur individuelle.

Aucun paiement réel n’est branché dans ce MVP.
